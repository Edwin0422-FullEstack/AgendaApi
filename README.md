# AgendaApi

Este es un proyecto de API desarrollado en C#, orientado a gestionar agendas o calendarios. El repositorio contiene la solución `AgendaApi.slnx` y una carpeta principal `AgendaApi` que probablemente alberga la lógica del API.

## Características principales

- API desarrollada en C#.
- Enfoque en la gestión de agendas, eventos o calendarios.
- Estructura de proyecto compatible con herramientas estándar de .NET.

## Estructura del proyecto

```
.
├── .gitattributes
├── .gitignore
├── AgendaApi.slnx
└── AgendaApi/
```

- **AgendaApi.slnx**: Archivo de solución principal de Visual Studio.
- **AgendaApi/**: Carpeta principal del código fuente.

## Requisitos

- [.NET SDK](https://dotnet.microsoft.com/download) (versión recomendada: la más reciente compatible con el proyecto)
- Visual Studio o cualquier IDE compatible con C#

## Instalación y ejecución

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Edwin0422-FullEstack/AgendaApi.git
   cd AgendaApi
   ```
2. Restaura los paquetes y compila la solución:
   ```bash
   dotnet restore
   dotnet build
   ```
3. Ejecuta la API (asegúrate de ubicarte en la carpeta del proyecto adecuado):
   ```bash
   dotnet run
   ```
